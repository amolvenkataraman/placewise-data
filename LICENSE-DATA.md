# Data licences

This repository publishes data packs for placewise as release assets. The packs are built from
third-party open datasets, and the data in each pack remains under the licences of the datasets it
was built from.

- Each release includes an `ATTRIBUTION.md` listing the sources used by the packs in that release,
  with each source's licence, website and required credit line. That file is the authoritative
  list for the release it is attached to.
- Each pack also records its source ids in its own `pack.json` and in the release's `index.json`.
- The licence of the placewise code does not apply to the data in the packs.
- Reuse of the data is governed by each source's own licence terms. Read them for your own
  obligations (for example, giving credit), particularly before redistributing a pack or data
  derived from it.

placewise's full source list is in
[ATTRIBUTION.md](https://github.com/amolvenkataraman/placewise/blob/master/ATTRIBUTION.md) in the
placewise repository.

The curated datasets in [`datasets/`](datasets/) are placewise's own work, licensed CC BY 4.0
(see [`datasets/LICENSE.md`](datasets/LICENSE.md)).
